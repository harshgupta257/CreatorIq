## 📌 Why CreatorIQ?

YouTube Studio gives you views. CreatorIQ gives you **intelligence**.

| What YouTube Studio gives you | What CreatorIQ gives you |
|---|---|
| Total views & watch time | ML-predicted growth trajectory (12 weeks) |
| Basic subscriber count | Competitor health scores & gap analysis |
| Simple engagement rate | Multi-source sentiment (YouTube + Reddit + News) |
| Upload history | Optimal upload day/hour heatmap |
| Nothing about competition | Content gap analysis vs 3 competitors |
| No external signal | Google Trends integration for topic demand |

## ✨ Feature Overview

<details>
<summary><b>📊 Overview Dashboard</b></summary>
<br/>

- **Inline metric strip** — Total Views, Subscribers, Videos, Avg Engagement, Avg Views/Video
- **Performance trend chart** — Full-width AreaChart of last 30 video views over time (Recharts)
- **Audience sentiment snapshot** — Positive / Neutral / Negative bars from combined multi-source analysis
- **Top Videos** — Horizontal bar chart of top 6 videos by views
- **Data source status** — Live indicators for YouTube, Reddit, Trends, News, Instagram
- **Intelligence insights** — Auto-generated insights from ML model (viral score, best day, top topic)

</details>

<details>
<summary><b>▶️ YouTube Analytics</b></summary>
<br/>

- **Channel overview strip** — Avatar, title, subscribers, views, video count, join year
- **Sortable video table** — Thumbnail, title, date, views, likes, comments, engagement rate, performance bar
- **Time range filter** — Last 30 / Last 90 / All Time
- **Upload frequency heatmap** — 7-day × time-slot grid from real publish timestamps
- **Best time to post** — Auto-calculated from historical performance, not guesswork
- **Export CSV** — Download your video data

</details>

<details>
<summary><b>🧠 ML Growth Predictions (Hero Screen)</b></summary>
<br/>

- **Model status bar** — Shows if Random Forest is trained or running in heuristic mode, with R² accuracy
- **Forecast summary strip** — Projected weekly views, viral potential score, best upload day, optimal duration
- **Growth trajectory chart** — Historical (solid) + 12-week forecast (dashed) in a single ComposedChart with reference line separating them
- **Title intelligence panel** — Boost % from numbers, question marks, colons in titles; power words; best example
- **Topic performance** — Horizontal bar chart: which content topics get the most average views
- **Upload time optimizer heatmap** — 7×6 grid (day × time slot), best cell highlighted with accent border
- **Video predictions table** — Actual vs predicted views, delta, confidence bar
- **Content recommendations** — Proven and trending topics with reasoning

</details>

<details>
<summary><b>💬 Audience Sentiment</b></summary>
<br/>

- **3-source comparison** — YouTube Comments, Reddit Discussions, News Media, side by side
- **Word frequency cloud** — Tag list of top words, sized by frequency
- **Sentiment over time** — Line chart with reference at 0 (neutral axis)
- **Top positive comments** — Real comment excerpts with author + likes
- **Top critical comments** — Real comment excerpts with author + likes

</details>

<details>
<summary><b>📈 Google Trends</b></summary>
<br/>

- **Status bar** — Shows tracked keywords, rate-limit state, and direct link to Google Trends
- **Interest over time chart** — Multi-line chart (one per keyword), accent + muted palette
- **Related queries** — Top and Rising queries with relative value bars
- **Geographic interest** — Ranked country list with relative bars

</details>

<details>
<summary><b>⚔️ Competitor Intelligence</b></summary>
<br/>

- **Add up to 3 competitors** — By @handle or URL, loaded live from YouTube API
- **Health score comparison** — Inline grade letters (A+/A/B/C/D/F) for each channel
- **Metrics comparison table** — Subscribers, views, avg views/video, views/subscriber, uploads/month, channel age — with winner highlighted
- **Bar chart comparison** — Subscribers and Avg Views/Video side by side
- **Content gap analysis** — Tags competitors cover that your channel doesn't, with "covered by x2/x3" badges
- **Strategic insights** — Auto-generated analytical rows comparing you vs competition

</details>

## 🚀 Getting Started

### Prerequisites

| Requirement | Version |
|---|---|
| Python | 3.11 |
| Bun | 1.3+ (or Node.js 18+) |
| Git | Any |

> **Already deployed?** Use the live versions directly:
> - 🌐 **Frontend:** [creator-iq-gules.vercel.app](https://creator-iq-gules.vercel.app/)
> - ⚙️ **Backend API:** [creatoriq-backend-986h.onrender.com](https://creatoriq-backend-986h.onrender.com/api/health)
>
> *(Note: Render free tier spins down after inactivity — first request may take ~30s to wake up)*

You'll also need API keys (free tiers work fine):

| API | Where to get it | Required? |
|---|---|---|
| YouTube Data API v3 | [console.cloud.google.com](https://console.cloud.google.com) | ✅ Yes |
| Reddit API (PRAW) | [reddit.com/prefs/apps](https://www.reddit.com/prefs/apps) | Optional |
| News API | [newsapi.org](https://newsapi.org) | Optional |

---

### 1️⃣ Clone the repo

```bash
git clone https://github.com/harshgupta257/CreatorIq.git
cd CreatorIq
```

---

### 2️⃣ Set up the Backend

```bash
cd CreatorLab/backend
pip install -r requirements.txt
```

Create a `.env` file:

```env
YOUTUBE_API_KEY=AIza...
REDDIT_CLIENT_ID=your_client_id
REDDIT_CLIENT_SECRET=your_client_secret
REDDIT_USER_AGENT=CreatorIQ/1.0 by u/youruser
NEWS_API_KEY=your_news_api_key
```

Start the Flask server:

```bash
python app.py
# ✓ Running on http://localhost:5000
```

---

### 3️⃣ Set up the Frontend

```bash
cd ../../creatorlab-frontend

# Install dependencies
bun install       # or: npm install

# Start dev server
bun run dev       # or: npm run dev
# ✓ Running on http://localhost:3000
```

> **Note:** Make sure Flask is running on port `5000` **before** opening the frontend.

---

### 4️⃣ Open the app

Navigate to **http://localhost:3000**, enter a YouTube channel handle (e.g. `@mkbhd`) and click **Analyze**.

## 🔌 API Endpoints

The Flask backend exposes these endpoints (all return JSON):

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/health` | Health check + API key status |
| `GET` | `/api/youtube/channel?url=` | Channel stats by URL or @handle |
| `GET` | `/api/youtube/videos?channel_id=` | Video list with stats |
| `GET` | `/api/youtube/comments?video_id=` | Top comments for a video |
| `GET` | `/api/sentiment/analyze?channel_id=&channel_name=` | Multi-source sentiment analysis |
| `GET` | `/api/predictions?channel_id=` | ML predictions (growth forecast, viral score, etc.) |
| `GET` | `/api/trends?query=&channel_id=` | Google Trends data |
| `GET` | `/api/reddit/sentiment?query=` | Reddit-only sentiment |
| `GET` | `/api/news?query=` | News sentiment |

## 🎨 Design System

CreatorIQ uses a **dark technical** design language — restraint as a feature.

```
Backgrounds:   #0c0c0e  #111114  #16161a  #1a1a1f
Borders:       #222228  #2d2d35
Text:          #ededf0  #888892  #50505a
Accent:        #5b6cf9
Positive:      #3fb950
Warning:       #d29922
Negative:      #f85149
```

**Rules enforced throughout:**
- ❌ No glassmorphism
- ❌ No gradient blobs
- ❌ No card grids of identical boxes
- ✅ Sections separated by `border-b`, not nested cards
- ✅ Full-width charts, not boxed
- ✅ Tables and inline strips over card grids
- ✅ `font-variant-numeric: tabular-nums` for all data
